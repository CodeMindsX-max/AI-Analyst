# AnalystAI — Product Overview & Requirements Specification

## 1. Executive Summary

**AnalystAI** is an Agentic Business Intelligence (Autonomous BI) application designed to bridge the gap between business stakeholders and complex relational databases. Unlike conventional dashboards that require manual metric configuration or basic SQL chatbots that output raw tabular responses without context, AnalystAI operates as a senior digital data analyst.

When given an ambiguous business query (e.g. *"Why did European margins contract in August despite higher gross revenue?"*), AnalystAI decomposes the request, inspects schema catalogs, retrieves canonical definitions from a business glossary and document RAG index, crafts verified read-only SQL, executes the query in a secure sandbox, computes variances, and delivers an executive answer supported by interactive charts, findings cards, and provenance evidence.

---

## 2. Target Personas

1. **C-Suite & Business Executives (CEO, COO, CFO):**
   - Need instant answers without waiting days for business intelligence tickets.
   - Demand concise summaries, key variance drivers, and strategic recommendations rather than raw SQL or unformatted tables.
2. **Commercial & Operations Leaders (Sales VPs, Regional Managers):**
   - Need to dissect operational performance, attainment percentages, and category trends on the fly.
3. **Data Analysts & Analytics Engineers:**
   - Need transparency into how the AI arrived at its conclusions.
   - Require access to the raw synthesized SQL query, execution plan, AST safety logs, and underlying schema profiling metrics.
4. **Academic Mentors & FYP Evaluators:**
   - Require clear demarcation between deterministic software architecture and genuine NLP/agentic reasoning algorithms.
   - Seek robust safety guardrails, clean modular boundaries, and structured data handling.

## 3. Core Feature Inventory

| Module | Purpose & User Capabilities |
|---|---|
| **Executive Overview** | Macro KPI cards, historical revenue trend chart, regional attainment breakdown, category sales table, and automated business alert cards. |
| **AI Analyst** | Core NLP interface. Natural language composer, prompt suggestions, 9-step execution timeline, executive summary, key findings cards, Recharts visualizations, SQL inspection, evidence drawer, and follow-up query refinement. |
| **Data Sources** | Catalog of registered enterprise analytical data stores. Connection diagnostic testing, metadata sync, and addition wizard for SQLite, PostgreSQL, Snowflake, BigQuery, and CSVs. |
| **Data Explorer** | Interactive database schema navigator. Real-time table list, column profile distributions (null %, distinct values, min/max/mean), and paginated live data previews. |
| **SQL Workspace** | Full SQL workbench. Multi-line editor, AST read-only safety validator, keyword formatter, query execution plan explainer, tabular results grid, and saved query library. |
| **Knowledge Base (RAG)** | Document ingestion and indexing engine. Uploads PDFs, Markdown, and TXT files, chunks text into semantic windows, and offers a diagnostic RAG search tester. |
| **Business Glossary** | Enterprise metric catalog. Standardized terminology, canonical formulas, domain tags, source tables, and steward assignments to prevent hallucinated metric logic. |
| **Dashboards** | Custom BI layouts. KPI cards, bar charts, line trends, and category distribution charts with viewer and builder modes. |
| **Reports** | Automated document-grade executive briefing generator with structured sections, markdown exports, and print-ready stylesheets. |
| **Saved Analyses** | Central library for bookmarking, tagging, pinning, and sharing historical insights generated by the AI Analyst. |
| **Schedules** | Cron-based scheduler for automated executive briefing dispatch, pipeline refreshes, and anomaly scans. |
| **Agent Runs** | Granular execution traces for every run, exposing duration, tool invocations, and step-level input/output telemetry. |
| **Audit Logs** | Immutable security trail tracking logins, queries executed, agent tasks, and role updates. |
| **Command Palette** | Universal `Ctrl+K` shortcut modal for instant global search across tables, metrics, reports, and navigation routes. |
